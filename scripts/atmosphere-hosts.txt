#  NeXoNetwork — Archivo de hosts para Atmosphere CFW  (Nintendo Switch real)
#
#  CÓMO INSTALAR:
#    1. Reemplaza TU_IP_AQUI (todas las líneas) por la IP de tu servidor NeXo:
#       - Misma red local que el servidor → usa su IP local (ej: 192.168.0.154).
#         Es más fiable: muchos routers no soportan NAT loopback, así que una IP
#         pública podría no resolver bien estando en la misma LAN.
#       - Redes distintas                 → usa la IP pública del servidor.
#    2. Copia este archivo a la SD de tu Switch:  /atmosphere/hosts/default.txt
#    3. Reinicia la Switch con Atmosphere.
#
#  FORMATO (hosts estándar de Atmosphere DNS-MITM, la IP va PRIMERO):
#       IP_DEL_SERVIDOR   patrón.de.dominio
#    NO al revés. Atmosphere solo resuelve IPs literales aquí, igual que
#    /etc/hosts. Ver docs/features/dns_mitm.md del propio Atmosphere.
#    Comodín soportado:  '*' = 0 o más caracteres.
#
#  CÓMO FUNCIONA:
#    Este archivo NO conecta a Nintendo — hace lo contrario. Atmosphere intercepta
#    el DNS de la consola. Con un solo comodín por dominio redirigimos TODOS los
#    subdominios de Nintendo hacia tu servidor NeXo, sin listarlos uno a uno.
#    Cuando la Switch intenta resolver "dauth-lp1.ndas.srv.nintendo.net" (o
#    cualquier otro), Atmosphere devuelve la IP de tu servidor. Nintendo nunca ve
#    tu consola → sin detección de CFW → sin ban. Tu servidor responde a cada
#    servicio (auth, amigos, BAAS, juego) y contesta 204 OK a la telemetría y a
#    las comprobaciones de actualización, para que ningún juego dé error.
# ══════════════════════════════════════════════════════════════════════════════
