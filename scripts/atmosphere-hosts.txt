#  NeXoNetwork — Archivo de hosts para Atmosphere CFW
#
#  CÓMO INSTALAR:
#    1. Reemplaza TU_IP_AQUI (todas las líneas) por la IP de tu servidor:
#       - Si la Switch está en la misma red local que el servidor: usa su
#         IP local (ej: 192.168.0.154). Es más fiable — muchos routers no
#         soportan NAT loopback, así que un dominio/IP pública podría no
#         resolver bien estando en la misma LAN.
#       - Si están en redes distintas: usa la IP pública del servidor.
#    2. Copia este archivo a la tarjeta SD de tu Switch:
#       /atmosphere/hosts/default.txt
#    3. Reinicia la Switch con Atmosphere
#
#  FORMATO (importante — es un hosts file estándar, IP primero):
#    IP_DEL_SERVIDOR   dominio.de.nintendo.net
#    NO al revés. Un dominio (como nexonetwork.space) como primer campo
#    NO funciona — Atmosphere solo resuelve IPs literales aquí, igual que
#    /etc/hosts. Ver docs/features/dns_mitm.md del propio Atmosphere.
#
#  CÓMO FUNCIONA:
#    Este archivo NO conecta a Nintendo — hace exactamente lo contrario.
#    Atmosphere intercepta el DNS internamente. Cuando la Switch intenta
#    resolver "dauth-lp1.ndas.srv.nintendo.net", Atmosphere devuelve la IP
#    de tu servidor en su lugar. Nintendo nunca ve tu consola → sin
#    detección de CFW → sin ban. Mismo principio que 90DNS, pero en vez
#    de bloquear, redirige a tu servidor que responde con datos válidos.
# ══════════════════════════════════════════════════════════════════════════════
